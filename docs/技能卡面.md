# 谋郭嘉·魂（卡面）

> 来源：lycium 在线制卡器 2.5.4 · 势力：魏 · 体力：4 · 性别：男

## 定策（锁定技）

游戏开始时，你选择一名其他角色令其获得「策」标记。
当你死亡时，你可以选择是否移除「策」。
你与拥有「策」的角色相互间无法造成伤害。

## 铸策

你的回合开始时，你给「策」添加以下其中一项效果：

1. 给「策」添加【回复体力】（限一次）；
2. 给「策」添加【额外执行一个出牌阶段：不摸牌】（限一次）；
3. 给「策」添加【使用牌造成的伤害+1】（限一次，永久）；
4. 给「策」添加【跳过一次弃牌阶段】。

## 沥血（锁定技）

当你体力值发生变动时，你与拥有「策」的角色各摸 X+1 张牌
（X 为「策」中已添加的效果数量）。
