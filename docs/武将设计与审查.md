## 谋郭嘉·魂（卡面）

> 来源：lycium 在线制卡器 2.5.4 · 势力：魏 · 体力：4 · 性别：男

### 定策（锁定技）

游戏开始时，你可以选择一名其他角色令其获得「策」标记；
若你放弃发动，本局此技能不再生效。
当你死亡时，你可以选择是否移除「策」。
你与拥有「策」的角色相互间无法造成伤害。

### 铸策

你的回合开始时，你给「策」添加以下其中一项效果：

1. 给「策」添加【回复体力】（限一次）；
2. 给「策」添加【额外执行一个出牌阶段：不摸牌】（限一次）；
3. 给「策」添加【使用牌造成的伤害+1】（限一次，永久）；
4. 给「策」添加【跳过一次弃牌阶段】。

### 沥血（锁定技）

当你体力值发生变动时，你可以摸 X+1 张牌
（X 为「策」中已添加的效果数量）；
若场上没有「策」，你摸一张牌。

### 1. 四将定稿文本（手写卡校准稿）

#### 名·陆逊　四血　吴

- **连营**：锁定技，每当你因非使用和打出而失去牌时，你获得X个"谦"标记（X为本次失去牌数的一半，向上取整；2026-09-13 校准）。当你没有手牌时，你将手牌摸至体力上限。（"没有牌"口径 2026-09-13 校准：没有**手牌**即触发，不要求装备/判定区全空）出牌阶段开始时，你摸等同于"谦"数量的牌，并弃置所有的"谦"。结束阶段，若你使用或打出的牌不大于你的体力值，你摸等同于你弃牌阶段弃置牌的数量。
- **炽炎**：出牌阶段限X次（X为游戏轮次），你可以弃置等同于你当前体力值的牌，并对一名角色造成一点火焰伤害，然后你可以弃置一张牌，视为使用【铁索连环】。结束阶段，若你以此法造成的伤害不小于你的体力值，你可以对所有处于连环状态的角色造成一点火焰伤害，并弃置其装备区内的所有牌。
- **谦逊**：锁定技，当你受到伤害时，若你的"谦"小于体力上限，你进行一次判定，若结果为红色，你摸两张牌；若你的"谦"大于体力上限，你可以弃置等同于你体力值的"谦"，你令此伤害-1；若你的"谦"等于体力上限，你免疫此伤害。
- **彰才**（神威技）：出牌阶段发动，本回合内你使用牌无次数和距离限制。（2026-09-13 校准：持续到回合结束，非本局游戏）

#### 名·刘备　四血　蜀

- **仁德**：游戏开始时，你获得3个"仁"标记。回合开始时，你收回所有的"仁"。出牌阶段，你摸等同于你身上"仁"的数量的牌。当一名拥有"仁"的角色被牌指定时，你可以失去一点体力或两张牌，令此牌无效（每回合限一次）。结束阶段，你可以将你身上的"仁"分配给任何不同的角色。
- **章武**（神威技）：每局游戏限一次，回合开始时你多执行一个出牌阶段，且本回合使用牌无次数限制。
- **兴汉**（主公技）：游戏开始时，你获得一个"仁"。当蜀势力角色对你造成伤害时，你免疫。（每角色每回合限1次）

#### 名·杜预　四血　群

- **武库**（锁定技）：当场上有人上装备时，你获得一个"备"标记，并摸一张牌。每回合限一次，你可以消耗一个"备"标记，将一张区域内的牌当非装备牌使用或打出。（"备"标记数量上限为5）
- **破竹**：每回合限一次，出牌阶段，你可以选择一种牌名，你本回合可以无次数与距离限制地使用此牌。若你本回合使用此牌造成过伤害，本游戏你使用此牌名无次数限制并无距离限制。
- **振鞘**（锁定技）：当你装备武器牌时，你使用牌无法被响应。当你造成伤害时，你可以令其免疫此伤害，并获得其装备区内的所有牌。当你使用【杀】时，此【杀】的伤害+X（X为你装备牌的攻击范围-你的体力值，且X最小为0）。
- **灭吴**（神威技）：每局游戏限一次，出牌阶段，你可以摸X张牌（X为标记数量+你的体力上限）。

#### 名·陆抗　四血　吴

- **毁堰**：出牌阶段，你可以选择一个区域令其失效并获得对应效果：①武器区：使其造成的伤害+1；②防具区：每回合第一次受到伤害时，你免疫此伤害；③进攻马：使用牌无法被响应；④防御马：摸两张牌；⑤判定区：无视距离并使用牌无次数限制；⑥手牌区：分配X点伤害给任意角色（X为你的体力值-1）。
- **抗晋**（锁定技）：当你受到体力值不小于你的角色造成的伤害时，你可以弃一张牌，并进行一次判定，如果颜色为红，你免除此伤害。当你造成伤害后，你可以令一个区域的状态本轮与你相同，然后你选择装备区内的一项恢复（每回合限两次；2026-09-13 用户校准）。
- **背水**（神威技）：每局游戏限一次，出牌阶段，你可以恢复你的所有区域。

### 2. 神威技类别（用户定义，已录入 README）

> 锁定技，当你击杀一名角色时，此技能使用次数+1，每局游戏限一次。

落地口径（经用户澄清）：

- 神威技**初始使用次数为 1**（开局即可用一次）；
- 你**首次击杀**角色时使用次数 +1（该加成每局游戏只触发一次，之后再杀不叠加）；
- 一局内至多 **2 次**。首杀加次数为锁定效果，自动生效。

⚠ 正文矛盾处理：章武/灭吴/背水的正文自带"每局游戏限一次"，与类别规则（最多 2 次）冲突，
**按类别规则实现**（正文里的那句视为赘述）。

#### 实现模型（extension.js）

- 记账位：`player.storage.tdgx_sw[技能名]` = 剩余次数（各技能 `init` 置 1）；
  `player.storage.tdgx_sw_bonus[技能名]` = 是否已领首杀加成。
- `tdgx_shenwei_kill`（隐藏技，`trigger:{source:'dieAfter'}`，forced）：击杀者为技能主人时，
  给每个未领加成的神威技 +1 次。
- 各神威技 `filter` 检查剩余次数、`content` 开头扣减。
- 为什么不用 `limited:true`：引擎的限定技是"一次性"模型（awakenSkill 退役），
  撑不起"1 + 首杀1"的两次模型，故手工记账。

### 9. 事故记录 · 毁堰⑥「分配伤害」无限循环（2026-09-12 第五轮）

**用户报告**：失去手牌区（毁堰⑥）后造成伤害，会「无限让其他角色的区域失效，而且该效果无法取消」。

#### 9.1 根因：`event.redo()` 回不到带守卫的那一步

毁堰⑥ 的伤害分配原本写成：

```js
'step 3'
if (!event.lkX || event.lkX <= 0) { event.finish(); return; }   // ← 唯一的终止判据 + 唯一的「再问一次」
player.chooseTarget(...)
'step 4'
if (result.bool && result.targets.length) {
    result.targets[0].damage(1);
    event.lkX--;
    event.redo();                                              // ← 错在这里
}
```

引擎语义（当次核实 `game.js`）：

| 事实 | 位置 |
|---|---|
| `goto(n)` 是 `this.step = n - 1` | `game.js:31959-31961` |
| `redo()` 是 `this.step--` | `game.js:31962-31964` |
| `step` 的 `+1` 发生在 **content 返回之后** | `game.js:41806` |

⇒ **`redo()` 在 step 4 里等价于「原地重跑 step 4」**，它回不到 step 3：既不重新询问、也不再
检查 `lkX`。而 step 4 用的 `result` 取自 `event._result`（`game.js:41676`），它仍是 step 3 那次
`chooseTarget` 的旧结果——因为 damage 事件的 content **全文没有 `result` 赋值**，而引擎只在
`event.result` 为真时才回填父事件（`game.js:41735-41738`）⇒ `result.bool` 恒为真、
`lkX` 一路减到负数也没人看 ⇒ **对同一目标无限重复伤害**。

**为什么实机表现是「无限让别人的区域失效」**：每次伤害都会触发 `lkang_kangjin_copy`
（`trigger:{source:'damageEnd'}`），而它的 `filter` 只看"自己还有没有已失效区域"——
手牌区/判定区的失效状态抗晋并不恢复（step 3 只列 e1–e4）⇒ 每 1 点伤害都问一次
「选一名角色复制失效状态」，Loop 不结束 ⇒ 玩家**取消不掉**（取消了下一轮伤害又立刻再问）。

**修法**：`event.redo()` → `event.goto(3)`。回到 step 3 后：每 1 点伤害都要重新指定目标
（可取消），`lkX` 归零即 `finish()`。这也是本文件其它循环的既有写法
（`cm_taozei` 的 `goto(3)`、`mlb_rende_give` 的 `goto(1)` —— 都是"跳回带守卫的询问步"）。

#### 9.2 证据（`atlas/tools/probe-loop-termination.mjs`）

探针复刻事件循环语义，跑真实 content（毁堰 + 抗晋·同轨），两个方向都验：

| 场景 | 结果 |
|---|---|
| 正例 A：现行实现，一路选目标 | 终止；伤害 3（hp4 ⇒ X=3）；毁堰询问 3 次；抗晋发动 3 次 |
| 正例 B：现行实现，第 2 次取消 | 终止；伤害 1；询问 2 次 —— **可取消** |
| 反例 C：把 `redo()` 放回去 | **不终止**（401 步保护上限）；伤害 23、抗晋发动 23 —— 与用户现象一致 |

反例 C 是这次修复的"验证器校准"：如果哪天有人把 `redo()` 写回来，探针必须失败。

### 10. 事故记录 · `cardUsable` mod 的 NaN —— 「只能用基本牌」三连（2026-09-12 第六轮）

**用户报的三个现象**（其实**同一个根因**，零报错）：

1. 自制武将**有时**只能用基本牌，其他牌全灰；
2. 名·陆抗**判定区失效后**无法使用锦囊牌；
3. 名·陆逊**只能使用【酒】【杀】**。

#### 10.1 根因：`num + 99` 在 `num === undefined` 时得到 NaN

`cardUsable` mod 的第三个参数 `num` 来自**牌自己的 `usable` 字段**：

```js
// game.js:33214-33238  lib.filter.cardUsable
var num=info.usable;                                        // ← 牌定义里没有 usable 字段 ⇒ undefined
if(typeof num=='function') num=num(card,player);
num=game.checkMod(card,player,num,'cardUsable',player);      // ← mod 链：我们的 num+99 在这一步
if(typeof num!='number'){ return (typeof num=='boolean')?num:true; }   // ★ NaN 的 typeof 就是 'number'，**放行**
if(player.countUsed(card)<num) return true;                  // ★ countUsed(card) < NaN 恒为 false
...cardUsableTarget 兜底（本项目没有这类 mod）...
return false;                                                // ⇒ 这张牌被判「不可使用」
```

而**锦囊/装备全都没有 `usable` 字段**——全库只有两张牌写了它：

| 牌 | 字段 | 出处 |
|---|---|---|
| 【杀】 | `usable:1` | `card/standard.js:91` |
| 【酒】 | `usable:1` | `card/extra.js:62` |
| 【无中生有】/【顺手牵羊】/装备牌… | 无该字段 | `card/standard.js:1017` / `1206` / `560` |

⇒ 我们的 mod 一旦生效，`undefined + 99 = NaN` → 上面第 4 行判 `countUsed(card) < NaN` = false →
**除【杀】【酒】外全部不可使用**。这正好解释了"为什么偏偏只剩酒和杀能用"。

`game.checkMod`（`game.js:44285-44302`）会把每个 mod 的返回值写回累加值（`NaN` 一路传出去），
所以只要**任意一个** skill 的 `cardUsable` mod 命中这条路径，这个玩家的牌就废了。

#### 10.2 六处同一写法（前四处无判据、后两处条件命中即中招）

| 技能 | 触发条件 | 对应用户现象 |
|---|---|---|
| `lx_zhangcai_mod`（名·陆逊 彰才·纵横） | **常驻武将数组，开局即生效** | 现象③「陆逊只能用酒和杀」 |
| `mlb_zhangwu_mod`（名·刘备 章武） | 发动章武后（临时技） | 现象①「有时」 |
| `cm_taozei_free`（转·曹髦 讨贼） | 压入牌堆底达标后（临时技） | 现象①「有时」 |
| `lkang_hy_mod`（名·陆抗 毁堰·阵） | **判定区失效期间** | 现象②「判定区失效后用不了锦囊」 |
| `dy_pozhu_turn` / `dy_pozhu_perm`（杜预 破竹） | 破竹选中的那个牌名 | 现象①（只在选中锦囊时） |

**修法**（六处统一）：先判 `num` 再算术 ——

```js
cardUsable: function (card, player, num) {
    if (num === false) return false;      // 别的技能已判「不可使用」⇒ 不覆盖它
    if (typeof num != 'number') num = 0;  // 牌本身没有次数上限 ⇒ 当作 0 再加
    return num + 99;
},
```

#### 10.3 证据（`atlas/tools/probe-cardusable-nan.mjs`）

复刻 `lib.filter.cardUsable` + `checkMod` 的语义，装载扩展、按场景跑五个牌样本
（杀 / 酒 / 无中生有 / 顺手牵羊 / 青釭剑），并**把守卫删掉造一份反例**：

| 场景 | 现行实现 | 反例（删掉守卫） |

| 名·陆逊（彰才常驻） | 五张全可用 | 杀/酒 可用；锦囊/装备 **不可用**（mod 返回 NaN） |

### 名·关羽　五血 / 蜀

#### 武圣（锁定技）

> 你可以将**恰好两张**手牌转化为一张【杀】使用或打出。若这两张牌均为红色，此【杀】造成伤害后你回复1点体力；若均为黑色，此【杀】造成的伤害+1；若两张花色不同，此【杀】不计入次数限制。以上效果可叠加。

**实现要点**
- 转化出口两个：`viewAs` 两牌 → 普通【杀】；单牌 → 伤害属性可指定（=【火杀】/【雷杀】语义）。

- 属性指定落在**伤害**上，不造假牌名。

**★ 平衡（强烈建议再点一下）**

- a) 单牌转化**每回合限一次**；
- b) 单牌转化**不计入次数上限**这条去掉（只保留属性指定）；
- c) 维持原样（我按原文实现，但强度评审会标为"超模"）。

#### 破敌（神威技，每局限一次）

> 回合内，你可以令一名其他角色获得「破」。
> 本回合**你每次对其造成伤害时**，令**其**免疫之，然后其获得一个「破」。
> 你回合结束时，拥有「破」的角色失去X点体力（X为其拥有「破」的数量）。

**裁定要点（按用户明确指示）**
- 免疫的受益者是**被攻击者**（不是关羽自己）；
- 触发时机是**造成伤害时**（即伤害结算前，令其免疫）。

**★ 三处必须再确认（否则技能自我抵消 / 无法执行）**

1. **标记无法累积**：免疫发生在**造成伤害时**，而「破」的结算在**同一个回合结束时**。

   建议写成"你回合结束时"→ 改为**下个回合结束时**，或明确"每次令其免疫即获得1枚，可叠加"。
2. **与〖武圣〗的加伤冲突**：【杀】的伤害被免疫后，武圣的"+1 伤害"等于白费。
   是否需要写明"被免疫时〖武圣〗的回血不触发"？
3. **强度方向**：这个技能目前是**纯帮对手**（替对手免伤）+ 回合结束扣其血。

### 名·关羽　五血 / 蜀

#### 武圣（锁定技）

> 原文：你可以将任意数量的牌转化为一张任意属性的杀。当你将两张红色的牌转化为【杀】使用或打出时，如果此杀造成了伤害，你回复一点体力。当你将两张黑色的牌转化为【杀】使用或打出时，此【杀】伤害+1。当你将两张不同花色的牌转化为【杀】使用或打出时，此杀无次数限制。

**【歧义】"任意数量的牌"没有上下限，且与三条加成条件冲突。**
三条加成全部以"**两张**"为前提，但主句允许"任意数量"。当玩家用 3 张或 5 张转化时：
这些加成是否成立？"两张红"是指"恰好两张且都红"、"至少两张红"、还是"其中的两张红"？
→ 无法执行。

> **改写**：
> 锁定技，你可以将**恰好两张**手牌转化为一张【杀】使用或打出（花色与属性由你指定）。
> 若这两张牌均为红色，此【杀】造成伤害后，你回复1点体力；
> 若这两张牌均为黑色，此【杀】造成的伤害+1；
> 若这两张牌花色不同，此【杀】不计入次数限制。

**【冲突】"任意属性的杀"超出标准规则。**
标准《三国杀》的【杀】只有**颜色**（红/黑）与**花色/点数**，没有"属性"字段；
属性（普通/火/雷）属于**伤害**的属性，由技能或【火杀】【雷杀】这类牌决定。
写成"任意属性的杀"会让引擎无法建模（该牌既不是【火杀】也不是【雷杀】）。

> **改写**：把"属性"落在**伤害**上——"此【杀】造成的伤害的属性由你指定"，
> 或者直接限定为"视为一张【火杀】或【雷杀】"（二选一、发动时声明）。

**【平衡】红色分支 = 稳定的自我续航。**
5 血 + 每回合一张"造成伤害就回 1 血"的【杀】，等于把输出转成血量，长期收益极高。
建议加"每回合限一次"或把回复改为"回合结束时若此【杀】造成过伤害，你回复1点体力"。

**【命名】"两张不同花色的牌"与"两张红色/黑色"可能同时成立**（例如 ♥A + ♠K 是一红一黑、
花色不同）。**三条加成是否可以叠加？** 原文没说。

> **改写**：加一句"以上效果可叠加"，或写成互斥的三选一（推荐叠加，强度可控）。

#### 义绝（回合开始时）

> 原文：回合开始时，你可以令其他角色依次选择是否交给你一张手牌，如果其没有选择交给你手牌，则其获得1枚"绝"标记，该角色于结束阶段失去"绝"。你对拥有绝的角色使用牌无次数限制。

**【歧义】"其没有选择交给你手牌"覆盖两种不同情况**：主动选择"不交"、与**无手牌可交**。
后者不应受罚（无牌可交却被标记 = 不合理）。

> **改写**：若其选择不交给你手牌**且其有手牌**，其获得1枚「绝」。

**【歧义】"该角色于结束阶段失去'绝'"——是谁的结束阶段？**
是义绝拥有者（关羽）的结束阶段，还是获得「绝」那个角色自己的结束阶段？
两种读法强度差别很大（前者意味着「绝」能跨过对方回合，后者只在本回合有效）。

> **改写**（推荐按"获得者的结束阶段"）：该角色于**其**结束阶段失去所有「绝」。

**【命名】「绝」标记的效果挂在哪一方？** 原文把效果写在义绝里
（"你对拥有绝的角色使用牌无次数限制"），但「绝」是**别人身上的标记**。
若关羽失去义绝（被【乐不思蜀】类效果影响、或技能被移除），这些标记会变成**死标记**。
标准做法是让"标记的规则"独立成一个子技能。

> **改写**：拆出子技能——
> **绝**（标记）：拥有「绝」的角色成为〖义绝〗拥有者使用牌的目标时，〖义绝〗拥有者对其使用牌无次数限制。
> 或在义绝里写清"你失去〖义绝〗时，移除场上所有「绝」"。

**【歧义】获得的手牌是否公开？** "交给你一张手牌"是按什么选（自己挑还是随机）？
标准做法是**由交牌者自己选择**并暗置。

> **改写**：令其**选择一张手牌**交给你（背面朝上，其余角色不可见）。

**【冲突】"令其他角色依次选择"缺少对无手牌者的处理与顺序定义。**
"依次"应按**座位顺序**（从你下家开始），且无手牌者自动跳过（不算"没有选择交给你"）。

> **改写**：你令其他角色**按座位顺序**依次选择是否交给你一张手牌；无手牌者跳过。

**【平衡】义绝是"稳赚"设计。** 交牌 = 对手亏 1 张手牌；不交 = 送「绝」，
让关羽对**其**使用牌无次数限制 ⇒ 对手两难，但两害相权往往只能交牌。
关羽本身 5 血，再加"对多人无次数限制"的输出空间，整体偏强。
建议：「绝」只在**该角色的回合内**有效，或改为"你对其使用**第一张**牌无次数限制"。

#### 破敌（神威技，每局限一次）

> 原文：回合内，你可以令一名角色获得"破"标记，本回合你每次对其他角色造成的伤害时，令其免疫之，并改角色获得一个"破"。你回合结束时，拥有"破"的角色失去X点体力。（X为其拥有"破"的数量）

**【歧义（严重）】"令其免疫之，并改角色获得一个'破'"——"其"指代不清，且导致技能自我矛盾。**
按字面：A）你每次对他人造成伤害 → 该伤害被免疫；B）该角色获得一个「破」。
那么：**这个技能只让敌人免伤、毫无收益**，同时还要花掉每局限一次的额度。
若是笔误（应为"令**你**免疫之，并**你**获得一个破"），则强度又变成"免伤 + 攒标记"。

> **改写**（按"自己免疫并攒标记"的意图）：
> 回合内，你可以令一名其他角色获得「破」。本回合你每次受到伤害时，防止之，然后你获得1枚「破」。
> 你的回合结束时，每名拥有「破」的角色失去X点体力（X为其拥有的「破」数量），然后其移去所有「破」。

**【冲突】"免疫伤害"与"造成过伤害"互斥，会让后续效果永不触发。**
标准规则中"伤害被防止"时**不算造成过伤害**。若原文意图是"对敌人造成伤害后获得标记"，
那么免疫与获得标记这两件事在规则上互斥，无法同时成立。

> **改写**：见上（把"获得标记"的触发条件改为"你受到伤害时"，而不是"你造成伤害时"）。

**【歧义】"破"的清除时机未定义。** 原文只在回合结束结算失血，没说标记是否移除。
若不移除，标记会持续累积 ⇒ 每回合结束滚雪球式掉血。

> **改写**：结算后**移去所有「破」**（写明）。

**【平衡】X 的上限过高。** 若一回合内能攒到 3~4 枚「破」，回合结束一次性失去 3~4 点体力
对 4 血角色是**直接致死**级别的惩罚。且这是"每局限一次"的技能，一次性爆发过强。

> **改写**：X 改为"其拥有的「破」数量**且至多为你已损失的体力值**"，
> 或把"失去X点体力"改为"受到X点火焰伤害"（可被防止/转移），降低硬解能力。

### 名·诸葛亮　四血 / 蜀

#### 七星（每轮开始时）

> 原文：每轮开始时，你弃置你武将牌上的所有"星"，并展示牌顶的7张牌并置于你的武将牌上称为"星"。你可以像手牌一样使用或打出"星"。回合内，当你使用或打出一张"星"后，选择一张牌弃置。

**【歧义】"弃置你武将牌上的所有星"——被弃置的星去哪？** 进弃牌堆？还是回到牌堆底？
"弃置"在标准规则里意味着进弃牌堆，但这里同时又要"展示牌顶 7 张"作为新星，
等于**每轮把上一轮的星全部换成新 7 张**——那旧星被浪费掉，描述上很反直觉。

> **改写**：每轮开始时，你**将你武将牌上的所有「星」置入弃牌堆**，然后展示牌堆顶7张牌
> 置为「星」。（若意图是保留旧星，则改为"将牌堆顶的牌补至7张"）

**【歧义（严重）】"回合内，当你使用或打出一张'星'后，选择一张牌弃置"——代价与收益不成比例。**
用 1 张星 = 少 1 张资源，还要额外弃 1 张牌 ⇒ 净亏 2 张。这会让玩家**永远不想用星**，
与"可以像手牌一样使用"的设计意图矛盾。

> **改写**（三选一，按意图）：
> a) 去掉弃置代价："你可以像手牌一样使用或打出「星」。"
> b) 把代价改成收益："你使用或打出「星」后，摸一张牌。"
> c) 若确实要代价，则给星额外强度："你使用「星」无距离与次数限制；使用后弃置一张牌。"

**【冲突】"星"放在"武将牌上"与"像手牌一样使用"存在规则摩擦。**
武将牌上的牌**不属于任何区域**（不是手牌、不是装备、不是判定区），标准规则里
"使用手牌"要求牌在手中。原版《三国杀》中"木牛流马""七星"这类都是**特殊区域**，
需要在技能里明确"视为手牌"或直接使用该区域。

> **改写**：写明"你武将牌上的「星」视为你的手牌（可被其他角色的技能指定，
> 但不计入你的手牌数）"——否则"手牌数"相关的判定会集体出错。

**【歧义】"星"的数量上限与可见性。** 7 张星是否对其他角色可见？被其他角色拿走时如何处理？

> **改写**：补一句"「星」对其他角色可见；「星」被移出时进入弃牌堆"。

**【平衡】每轮白得 7 张可用资源，强度显著偏高**（相当于每轮一次额外的"摸7"，
且不受手牌上限约束）。建议：改为"展示牌堆顶 3 张"，或让星**只能用于〖空城〗与〖火计〗**，
不开放为通用手牌。

#### 空城（锁定技）

> 原文：当你没有手牌时，如果你成为了牌的目标，你可以弃置1张"星"令此牌无效化，然后将此牌加入"星"中。

**【歧义】"令此牌无效化"的作用范围：整张牌，还是只对你？**
若是**多目标牌**（如【万箭齐发】、【南蛮入侵】、【借刀杀人】），
"整张牌无效化"意味着**其他目标也一起被免除**，强度暴涨。

> **改写**：你可以弃置1张「星」，令**此牌对你无效**，然后将此牌置为「星」（该牌不对你生效）。

**【冲突】与【无懈可击】的结算顺序未定义。**
"无效化"在标准规则里是【无懈可击】的专属效果。技能直接"令牌无效"需要说明：
是否经过【无懈可击】响应？是否可以被【无懈可击】反制？

> **改写**：补一句"此无效化不可被【无懈可击】响应/或可被【无懈可击】响应"（择一写明）。

**【歧义】"将此牌加入星中"——该牌从哪个区域来？**
作为目标时，该牌通常仍在**其他角色的手牌里**或**结算中**。把它拿走会产生
"牌在结算中被移动"的规则冲突（标准规则禁止结算中移动该牌）。

> **改写**：改为"此牌结算结束后，若此牌仍在弃牌堆，你将其置为「星」"，
> 或简化为"你获得1枚「星」"（不指定来源牌）。

**【歧义】是否可以重复发动？** 面对同一张多目标牌 + 多张星，能否连续弃星多次？
原文未限制"每张牌一次"。

> **改写**：每张牌限一次（"当你成为牌的目标时，你可以弃置1张「星」……每张牌限一次"）。

**【平衡】弃 1 张星换 1 张牌 + 挡一次 = 净赚，且〖七星〗每轮补满 7 张星。**
空城让诸葛亮在"无手牌"状态下几乎免疫所有指定，配合七星每轮刷新，防御过强。
建议：弃星改为"弃置2张「星」"，或限定"每回合限一次"。

#### 火计（神威技，每局限一次）

> 原文：你可以弃置所有的"星"，选择一名角色，使其受到X点火焰伤害。（X为你的体力值）

**【歧义】X 的取值时机。** "你的体力值"是**发动时**的，还是**结算时**的？
若中间有插入结算，取值会不同。

> **改写**：X 为你**发动此技能时**的体力值。

**【冲突】"弃置所有的星"可能为 0 张。** 星为 0 时是否还能发动？
（弃 0 张 = 无代价，白嫖 X 点火焰伤害）

> **改写**：补"若你以此法弃置了至少1张「星」"作为发动条件。

**【平衡】4 血武将 = 4 点火焰伤害**，且是直伤（可被铁索传导、可致命）。
配合〖七星〗每轮 7 张星，这个代价几乎不痛不痒。建议：X 改为"你已损失的体力值"
或"你的体力值且至多为3"，或改为"受到X点火焰伤害，X为你弃置的「星」数量"。

### 名·曹操　四血 / 魏

#### 奸雄（每轮开始时 / 受到伤害后）

> 原文：每轮开始时，你可以清除你身上的"略"。当你受到1点伤害后，你记录此牌X次于"智"中（X为本轮受到的伤害），并获得一个"略"，然后摸X张牌（X为略标记的数量）。

**【命名（严重）】一段话里出现三个标记：**略**、**智**、**奸**（后者只在〖志略〗里出现），
但没有任何一处说明它们各自的作用与关系。特别是"记录此牌于『智』中"——
"记录一张牌"的载体应该是一个**牌区**（像诸葛亮的"星"），却被写成了标记名。

> **改写**：统一为两个名字并各自定义：
> - **智**（区域）：你记录于此的牌，可供〖志略〗使用（放在武将牌上，可见）。
> - **略**（标记）：你每有1枚「略」，摸牌阶段外获得牌时额外摸1张（或直接写明其用途）。

**【歧义（严重）】"记录此牌X次于智中（X为本轮受到的伤害）"无法执行。**
"此牌"指造成伤害的那张牌（如【杀】）——**同一张牌记录 X 次**是什么意思？
是记录 X 份副本？还是记录 X 次引用（但牌只有一张）？若是"本轮累计受到的伤害"，
那么每受一次伤就要把**同一张牌**再记录一遍，数值会爆炸。

> **改写**：按意图二选一——
> a) "当你受到伤害后，你将造成此伤害的牌置于你的武将牌上，称为「智」"（每张牌记 1 次）
> b) "当你受到伤害后，你记录此伤害的属性与来源牌名"（记录文字而非实体牌）

**【歧义】"然后摸X张牌（X为略标记的数量）"——X 是"本次获得后"还是"获得前"的数量？**
且"略"若不清空，摸牌数会随受伤次数**线性甚至二次增长**。

> **改写**：明确"X 为你**获得此「略」后**拥有的「略」数量"，并给「略」设上限
> （例如"至多为3"），或改为"摸1张牌；若你拥有的「略」不小于2，改为摸2张牌"。

**【命名】"清除你身上的略"用的是"清除"，而其他地方用"弃置/移去"。**
标准用语建议统一为**"移去"**（标记的通用动词）。

> **改写**：每轮开始时，你可以移去你所有的「略」。

**【冲突】"每轮开始时，你可以清除"是可选效果。**
若玩家不选，标记会永久累积 ⇒ 与"每轮重置"的意图不符。
应明确"不选则保留"还是"强制清除"。

> **改写**：每轮开始时，你移去所有的「略」（强制），或写明"你可以……若你不如此做，则保留"。

**【平衡】"略"按受伤次数无限累积 + 每次受伤都摸牌 ⇒ 越被打越强**，
且 4 血身板配合"受伤摸牌"形成滚雪球。这是标准的"过强反馈回路"。
建议：每轮最多获得 1 枚「略」；且摸牌数封顶（如"至多摸2张"）。

#### 清正（每回合限一次）

> 原文：你可以令一名角色获得"治"。拥有"治"的角色回合开始时，你可以令其摸X张牌或弃置X张牌，并弃置"治"（x为你的体力值）。

**【歧义（严重）】"你可以令其摸X张牌或弃置X张牌"——是谁做选择？**
是你（清正拥有者）选，还是"拥有治的角色"选？前者是纯辅助/纯干扰，后者是被动应对。
两种读法差别极大。

> **改写**（按"你选"）：拥有「治」的角色回合开始时，**你选择一项**：
> 令其摸X张牌，或令其弃置X张牌；然后其移去「治」。

**【歧义】"弃置X张牌"是谁的牌、如何选？** 若指"拥有治的角色弃置自己的X张牌"，
则手牌不足时如何处理（能弃多少弃多少？还是不发动？）。

> **改写**：补"若其手牌不足X张，则弃置其所有手牌"。

**【命名】"治"标记**：与〖奸雄〗的「略」「智」并列无关联，命名上容易混淆（同音/同类字）。
建议改为更具指向性的名字，如「清」或「正」。

**【平衡】每回合限一次、但效果是"摸 X 张"（X=你的体力值，通常 4）。**
这意味着曹操每回合可以给任意角色（包括自己！）**白给 4 张牌**。
"一名角色"未排除自己 ⇒ 相当于每回合额外摸 4 张，属于**极强**。

> **改写**：① 明确"一名**其他**角色"；② 摸/弃的数量改为"X 的一半（向下取整）"或固定 2 张。

**【平衡】该"治"是永久标记（回合开始才触发），且可以被反复给予同一角色。**
若曹操给同一角色叠多个「治」，其回合开始会触发多次吗？原文未定。

> **改写**：每名角色至多拥有1枚「治」；或明确"多个「治」只触发一次"。

#### 志略（神威技，每局限一次）

> 原文：你可以按照记录顺序依次使用或打出"奸"中已记录的牌。（无距离、次数限制）

**【命名（严重）】"奸中已记录的牌"——「奸」这个区域从未定义过。**
〖奸雄〗里记录到的是"**智**"中，这里却写成"奸"。属于**未定义引用**，必须统一。

> **改写**：统一为「智」："你可以依次使用或打出你武将牌上「智」中记录的牌。"

**【歧义】"按照记录顺序"是强制顺序吗？中途的牌若已不在「智」中（被移走）怎么办？**

> **改写**：你可以按任意顺序使用或打出「智」中的牌；已被移走的牌不再可选。

**【歧义】"使用或打出"由谁决定？** 若记录的是【闪】，是"使用"还是"打出"（响应）？
"打出"需要有人对你出【杀】才能响应，而这是主动技能 ⇒ 实际不可行。

> **改写**：你可以使用「智」中的牌；其中【闪】【无懈可击】等响应牌改为"视为使用"。

**【平衡】一次性把记录的多张牌用完，且无距离与次数限制。**
若「智」里累积了 5~6 张牌（每轮被伤害都在记录），一个回合内全部打出，
等于"第二回合开始"。建议：限定"至多使用3张"，或改为"每回合限一次、每次1张"。

### 一、技能文本（按全部已裁定口径定稿）

#### 武翊（卡面一个技能名；实现上允许内部分装多个触发挂载点）

1. 你可以将一张【杀】当【闪】、【闪】当【杀】使用或打出。
2. 回合开始时，你从下列四项中选择一项，**先从牌堆中查找**该装备，牌堆中没有则从弃牌堆中查找，
   获得之；**两处都没有则该次不获得**：
   ①【进攻马】（即 -1马：你到他人的距离 -1）
   ②【防御马】（即 +1马：他人到你的距离 +1）
   ③【武器】
   ④【防具】
   > 判定口径：**所有 -1马都是进攻马；所有 +1马都是防御马**（按装备子类型判定，不需牌名清单）。
3. 你的手牌上限 +X（X = 你装备区内**已装备的栏位数**）。
   装备区为**标准四栏位**（武器 / 防具 / +1马 / -1马）。**不设宝具栏**。
4. 你造成伤害时（**不限伤害来源**），你可以弃置一张**武器牌**（装备区内或手牌中，两处均可），
   令此伤害 +1。**同一回合内不能多次发动**；同一次伤害**不能叠加**（仅指本项内部）。
5. 你受到伤害时，你可以弃置一张**防具牌**（装备区内或手牌中，两处均可），**完全抵消此伤害**
   （此伤害不发生 ⇒ 不算受到伤害，可躲过"受到伤害后"类触发）。
   **两处都没有相应牌时，不能发动此项。**
6. 当你装备区内有**进攻马**时，**每局第一次**你受到伤害，**免疫之**（此伤害不发生）；
   然后**你可以选择**弃置装备区内的进攻马。
   **当你装备区内的进攻马离开装备区时，你摸两张牌**（含被他人弃置/夺取、含装备区内的替换）；
   **若你保留该马，则不摸牌**。
   **同一栏位重新装备（含换另一张马）即刷新"每局第一次"**；**被他人夺走时同样刷新**。
7. 当你装备区内有**防御马**时，**每局第一次**你造成的伤害 +1，然后**你可以选择**弃置装备区内的防御马。
   **当你装备区内的防御马离开装备区时，你摸两张牌**（同上口径）。
   **同一栏位重新装备即刷新"每局第一次"**；**被他人夺走时同样刷新**。
8. 你使用或打出过的**基本牌牌名数**（**不同牌名**；**【火杀】【雷杀】不计为独立牌名**）
   **本局累计**达到：
   - 1：你使用基本牌无次数限制；
   - 2：你使用基本牌无距离限制；
   - 3：当你获得/失去装备时，你摸一张牌。
   达到 3 时 ①②③ **全部生效**（此后持续生效）。
   「获得/失去装备」**包含「移动」（装备区内部的替换与移出）**；**替换装备会同时触发两次**
   （旧牌失去 + 新牌获得）。**不包含「手牌 → 装备区」的放入**（该情形只算"获得"以外的操作，见下"裁定"）。

#### 摧锋

1. **每轮限一次**。每回合结束时，你可以摸一张牌并执行一个额外的回合
   （额外回合**包含判定阶段与摸牌阶段**）。
   **额外回合结束时，不能再发动本项。**
   > 额外回合内**可以再次触发 `武翊2`**（回合开始拿装备）—— 用户明确。
2. 每回合结束时，你可以从装备栏或手牌中弃置一张装备牌（**弃置是代价**），
   然后你可以**视为对当前回合角色使用一张【决斗】**，此【决斗】造成的伤害 +X
   （X = 本回合所有角色使用或打出【杀】的次数；**同一张【杀】指定多个目标按 1 次计**；
   **X 至多为 3**）。
   该【决斗】**不能以你自己为目标**；**至少造成 1 点伤害**
   （**若被【无懈可击】取消，则保底不成立**）。
   **若你没有装备牌可弃，则不能发动本项。**
3. 上述两项**在同一回合结束时都可以发动**。

### 三、强度与设计评估（按"娱乐向超模"定位）

#### 设计思路（优点）

1. **"装备库存管理"内核** —— 装备同时是**手牌上限、进攻资源、防御资源**，
   `武翊2` 每回合补充 ⇒ 独特的资源循环手感。
2. **`武翊` 与 `摧锋` 的张力** —— 装备既增值（3/4/5/6/7）又是消耗品（4/5/摧锋2）⇒ 取舍感强。
3. **`武翊8` 的"牌名成就"** —— 火杀/雷杀不算独立牌名之后，它奖励"用多样基本牌"，
   是**克制型**设计，不会立刻全能。

#### 强度定位（明确为娱乐向超模，此处只做说明，不主张削弱）

按全部裁定，本武将的**上限**大致是：

| 维度 | 表现 |
|---|---|
| **防守** | `武翊5` 可**反复完全抵消**（每回合弃防具即可）+ `武翊6` 每局一次免疫 ⇒ 对手输出几乎无效 |
| **进攻** | 单次伤害最高 **+4**：`武翊4` +1、`武翊7` +1、`摧锋2` X（至多3，但那是决斗）／另计 `武翊8①②` 基本牌无限次无距离 |
| **抽牌** | 马离开装备区一次 **摸 3 张**（6/7 的 2 张 + 8③ 的 1 张），而 `武翊6/7` 可**刷新** ⇒ 可反复取用 |
| **回合数** | 每轮最多 2 个回合（正常 1 + 摧锋1 额外 1），额外回合**还能再触发 `武翊2`** |
| **手牌上限** | +4（四栏位全满时） |

⇒ **远超标准 4 血武将**，接近"神将/娱乐向"强度。这是**已确认的设计取向**。
