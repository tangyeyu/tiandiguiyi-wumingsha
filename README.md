## 安装

1. 复制 `extension/extension.js` 到游戏根目录 `resources\app\extension\天地归一\extension.js`
2. 打开 `resources\app\game\config.js`，在 `extensions:[...]` 数组末尾追加 `'天地归一'`
3. 重启游戏 → 扩展管理 → 启用「天地归一」
4. **开一局新游戏**（角色包在开局注册）→ 选将界面选择「天地归一」包 → 任选本包武将

## 技能一览

### 谋郭嘉·魂（魏）

- **定策**（锁定技）：游戏开始时**你可以**选择一名其他角色令其获得「策」（放弃发动则本技能本局不再生效）；你与该角色相互间无法造成伤害；你死亡时可选择移除「策」
- **铸策**：回合开始时给「策」添加一项效果 —— 回复体力 / 额外执行一个出牌阶段（不摸牌）/ 使用牌造成的伤害+1（单目标）/ 跳过弃牌阶段（前三项各限一次并永久）
- **沥血**（锁定技）：体力值变动时可摸 X+1 张牌（X 为「策」效果数）；**若场上没有「策」，你摸一张牌**

### 转·曹髦（魏）

- **决境**：每轮开始时令全场各摸一张牌并转为闪电置于各自判定区；闪电判定时你摸牌；你自己的闪电判定成功时免伤、清空全场判定区的闪电并永久失去「决境」
- **奇技**（锁定技）：回合结束时夺取本回合未被你伤害过的角色各一张牌；受伤时可弃判定区一张牌免伤；有人受 ≥2 点伤害时你摸 X（体力值）或 Y（全场判定区牌数）张
- **讨贼**（锁定技）：每轮开始可将任意牌压入牌堆底，累计超过体力上限后可无视次数与距离使用牌堆底的牌

### 名·陆逊（吴）

- **连营**（锁定技）：因非使用和打出而失去牌时获得X个「谦」（X=失去牌数÷2 向上取整）；没有手牌时将手牌摸至体力上限；出牌阶段开始时按「谦」数摸牌并弃置全部「谦」；结束阶段若你使用或打出的牌不大于体力值，摸等同于弃牌阶段弃置牌数的牌
- **炽炎**：出牌阶段限 X 次（X 为游戏轮次），弃置等同于当前体力值的牌并对一名角色造成 1 点火焰伤害，然后可弃一张牌视为使用【铁索连环】；结束阶段若以此法造成的伤害不小于体力值，可对所有连环状态角色造成 1 点火焰伤害并弃置其装备区内所有牌
- **谦逊**（锁定技）：受到伤害时按「谦」与体力上限的关系 —— 小于则判定，红色摸两张；大于则可弃置等同于体力值的「谦」令此伤害 -1；等于则免疫此伤害
- **彰才**（神威技）：发动后本回合你使用牌无次数和距离限制

### 名·刘备（蜀）

- **仁德**：开局获得 3 个「仁」；回合开始时收回全场「仁」；出牌阶段按「仁」数摸牌；拥有「仁」的角色被牌指定时可失去 1 点体力或两张牌令此牌无效（每回合限一次）；结束阶段可将「仁」分配给不同角色
- **章武**（神威技）：回合开始时额外执行一个出牌阶段，且本回合使用牌无次数限制
- **兴汉**（主公技）：开局额外获得一个「仁」；蜀势力角色对你造成的伤害免疫（每名角色每回合限 1 次）

### 名·杜预（群）

- **武库**（锁定技）：场上有人装备牌时你获得一个「备」并摸一张牌（上限 5）；出牌阶段限一次，可消耗一个「备」将区域内一张牌当非装备牌**使用或打出**（牌名范围与「使用」一致，响应时按当前索要的牌名产出；「使用」与「打出」共用每回合一次的额度）
- **破竹**：每回合限一次，选一种你手牌里有的牌名 —— 本回合使用此牌无次数与距离限制；若本回合以此造成过伤害，则本局游戏使用此牌名无次数与距离限制
- **振鞘**（锁定技）：装备武器牌时你使用的牌无法被响应；造成伤害时可令此伤害免疫并获得受伤角色装备区内所有牌；使用【杀】造成伤害时此伤害 +X（X = 攻击范围 − 体力值，最小 0）
- **灭吴**（神威技）：摸 X 张牌（X 为「备」标记数 + 体力上限）

### 名·陆抗（吴）

- **毁堰**：出牌阶段选择一个自己的区域令其失效（每个区域整局只能选一次）并获得对应效果 —— 武器区：你造成的伤害 +1；防具区：每回合第一次受到伤害时免疫；进攻马：使用牌无法被响应；防御马：摸两张牌；判定区：无视距离且使用牌无次数限制（区内牌被弃置，后续延时锦囊无法放入）；手牌区：分配 X 点伤害给任意角色（X 为体力值 −1，手牌视为不可使用）
- **抗晋**（锁定技）：受到体力值不小于你的角色造成的伤害时，可弃一张牌并判定，红色则免除；造成伤害后可令一名角色的一个区域本轮与你状态相同，然后恢复你装备区内一个栏位（每回合限两次）
- **背水**（神威技）：恢复你所有已失效的区域

## 技能类别：神威技

本扩展自定义技能类别「神威技」，规则：

- **锁定技**。神威技初始使用次数为 **1**（开局即可使用一次）。
- 当你**击杀一名角色**时，此技能使用次数 **+1**；该加成**每局游戏限触发一次**（仅首次击杀有效，之后再击杀不叠加）。
- 一局游戏内最多使用 **2 次**（初始 1 次 + 首杀奖励 1 次）。首杀加次数为锁定效果，自动生效。

> 「神威技」为本扩展自定义类别，无名杀引擎无内置对应；实现上以共用标记记录已用次数与首杀奖励是否已发放。

本仓库的价值在于 `docs/开发心得.md` —— 无名杀自定义武将包**唯一正确姿势**的完整考证：
