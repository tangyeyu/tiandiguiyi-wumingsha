# 天地归一 · 谋郭嘉·魂

无名杀（Noname）**自定义武将包扩展** —— DIY 自制武将「谋郭嘉·魂」（定策 / 铸策 / 沥血），
适用于 **琉璃版 5.5（电脑版）**，为标准 `game.import('character')` 包格式。

## 内容

| 文件 | 说明 |
|---|---|
| `extension/extension.js` | 无名杀扩展文件（放入 `resources\app\extension\天地归一\`） |
| `docs/开发心得.md` | **完整研发心得**：三次翻车经历 + 引擎源码级机制研究（注册链 / 触发链 / subSkill 自动注册 / 额外出牌阶段正确姿势 / trigger 双键） |
| `docs/技能卡面.md` | 武将卡面文案（lycium 制卡器 2.5.4 定稿） |

## 安装

1. 复制 `extension/extension.js` 到游戏根目录 `resources\app\extension\天地归一\extension.js`
2. 打开 `resources\app\game\config.js`，在 `extensions:[...]` 数组末尾追加 `'天地归一'`
3. 重启游戏 → 扩展管理 → 启用「天地归一」
4. **开一局新游戏**（角色包在开局注册）→ 选将界面选择「天地归一」包 → 谋郭嘉·魂

## 技能一览

- **定策**（锁定技）：游戏开始时选择一名其他角色获得「策」，你与该角色相互间无法造成伤害；你死亡时可选择移除「策」
- **铸策**：回合开始时给「策」添加一项效果 —— 回复体力 / 额外执行一个出牌阶段（不摸牌）/ 使用牌造成的伤害+1（单目标）/ 跳过弃牌阶段（前三项各限一次并永久）
- **沥血**（锁定技）：体力值变动时，你与「策」各摸 X+1 张牌（X 为「策」效果数）

## 为什么值得看

本仓库的价值在于 `docs/开发心得.md` —— 无名杀自定义武将包**唯一正确姿势**的完整考证：
为什么不能放 `character\` 目录、为什么不能直塞 `lib.characterPack`、
为什么翻译必须用 `translate`（单数）、为什么**所有技能（含隐藏子技能）必须列进武将数组**（`filterTrigger` L33044 源码证据）等。
